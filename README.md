Este projeto tem como objetivo validar dados de e-mail, CPF, telefone e data a partir de um arquivo CSV, utilizando expressões regulares (Regex).

O programa utiliza os módulos re e csv para validar e ler os dados, além de tratamento de exceções para lidar com possíveis erros e uma exceção personalizada para identificar formatos inválidos.

Ao final da execução, é gerado um relatório com os registros válidos e inválidos, incluindo a quantidade de dados analisados e os motivos das falhas.

Para executar o programa, deixe os arquivos validador.py e dados.csv na mesma pasta, abra o terminal do VS Code e execute python validador.py. Quando solicitado, pressione Enter para utilizar o arquivo padrão.

O projeto foi desenvolvido para praticar leitura de arquivos, validação de dados e tratamento de erros em Python.
